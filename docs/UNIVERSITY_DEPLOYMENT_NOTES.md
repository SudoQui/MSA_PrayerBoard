# University deployment notes

Before installing the wallboard on a university network, obtain approval for the device, outbound web access and any remote administration agent.

Record:

* device hostname and serial number
* physical location and monitor model
* network connection method
* technical owner and content owner
* approved remote administrators
* recovery contact and spare SD card location

Do not expose SSH directly through public port forwarding. Prefer a university-approved private overlay network or Raspberry Pi Connect.
